# ShopSmart

ShopSmart is a fully developed Android application designed to provide a seamless shopping experience by allowing users to browse and filter store items efficiently.

## Features
- **Bottom Navigation Bar**: Easily navigate between different sections of the app.
- **Shop Fragment**: View store items categorized by departments.
- **Department Filter**: A top navigation bar within the Shop fragment to filter items by departments such as Vegetables, Butchery, and Bakery.
- **Firebase Integration**: Used for backend services.
- **Home Fragment**: Displays a welcome message and featured products.
- **Shopping Cart**: Add items to the cart for easy checkout.
- **User Authentication**: Secure login and registration system.
- **Checkout and Payment System**: Complete purchases seamlessly.
- **Real-time Inventory Updates**: Ensures accurate stock information.

## Tech Stack
- **Language**: Kotlin
- **IDE**: Android Studio
- **Backend**: Firebase
- **UI Components**: Android Views


## Administration
ShopSmart is managed by a dedicated team of administrators responsible for maintaining the app, monitoring transactions, and ensuring a smooth user experience. Admin capabilities include:
- **Product Management**: Adding, updating, and removing store items.
- **User Management**: Handling user accounts and permissions.
- **Order Tracking**: Overseeing placed orders and managing deliveries.
- **Analytics & Reports**: Monitoring sales, stock levels, and customer activity.

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/Novanard/ShopSmart.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Run the application on an emulator or a physical device.
